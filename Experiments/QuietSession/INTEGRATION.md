# Integration map (prototype, not wired)

1. At authenticated RPC open, retain `opened.tokId`. The coordinator lives in the RPC server process; create a fresh random lease id and callback nonce for each Begin. State machine file `Sources/QuietLeasePrototype/QuietLease.swift` has no XCTest/UI dependency. Never persist/revive leases on restart.
2. Add the RPC methods specified in `PROTOCOL.md`. On Begin, enqueue Shortcuts `shortcuts://run-shortcut?name=iCTRL%20Quiet%20Begin&input=text&text=<encoded-input>` using the existing `open_url` UI lane; redact that full URL from logs. URL launch acceptance leaves state `preparing`. Callback HTTP listener must be loopback-only on a fixed port, fixed `/quiet-callback` path, POST-only with size limits. `QuietCallback.parse` is a bounded body parser, not the listener itself. Bind the parsed deadline/action/nonce to the pending invocation and feed the state machine outside the UI lane. Never wait for callback while holding the UI lane.
3. Place the UI gate in the server immediately before every mutating Runner dispatch. Require random `automation_session` plus tokId for Agent. Missing session is explicit manual/legacy routing and must never automatically start Focus; while Agent lease exists reject other clients' UI mutation. Any supplied but invalid session fails closed. Use explicit takeover to suspend Agent before manual gate opens. Read-only RPC can remain available.
4. On End or timeout revoke gate first, then run Inspect/End Shortcut through UI lane. If callback confirms `off` or `preserved_user_focus`, complete. Otherwise retain `restoration_pending` diagnostics; never retry UI actions blindly. Server timer is a supplement to Set Focus Until absolute deadline. No Focus setter is assumed in native app.

Minis shell use: import `QuietClient` and pass the existing authenticated `rpc_call(method, params)` adapter. Enclose automated UI calls in `with QuietClient(rpc_call).session(ttl_seconds=120) as q:` and use `q.ui("tap", {"x":..., "y":...})`. If Begin/verification fails, the context raises and no tap is sent. Direct Minis RPC must be guarded server-side too; this wrapper alone is insufficient.
